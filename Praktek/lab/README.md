## Standar Format Folder Per Modul

Setiap subfolder modul disarankan memiliki struktur:

```text
modul-xx/
├── docs/            # Foto rangkaian / wiring diagram
├── src/             # Source code (.ino / .cpp / PlatformIO)
└── README.md        # Penjelasan tugas, pinout, dan hasil uji
```
